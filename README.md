## ▶️ Running the code

Each file has its own `main` method — compile and run individually:

```bash
javac "Link_list/Inserction_2/Tasks/Reverse_linked_list.java"
java Link_list.Inserction_2.Tasks.Reverse_linked_list
```

Or from inside the file's folder:

```bash
javac Reverse_linked_list.java && java Reverse_linked_list
```
